





Présentation

Portfolio Saved-Obed Fullstack Developer.

Ceci est un mini portfolio pour me présenter en tant que développeur web. je l'ai réalisé comme projet de fin de formation du programme débutant en développement web de D-clic.
Il est constitué de 4 pages:
- page d'accueil
- page projets
- page à propos
- page contact

ce portfolio présente à la fois mes compétences en développement web , mes projets et la façon dont ce métier est réorienté aujourd'hui à travers l'intelligence artificielle.


Mes quelques difficultés

- l'optimisation des images
- la mise en ligne des projets sur github pages
- l'optimisation du seo
- la mise en place du formulaire de contact
- la mise en place du menu burger sur mobile, donc en gros ; la responsivité du site
- la mise en place des animations, transitions, effets de survol
- la validation du formulaire de contact, surtout l'email pour qui on utilise des regex
 

Résumé qualité

1- Acessibilité

- probleme: le seo n'est pas optimisé, les liens vers deux projets était en localhost;
-correction: j'ai mis les liens en ligne et optimiser le seo
-resultat: le seo et les liens sont optimisés

2- performance

- probleme: le temps de chargement des images étaient un peu long;
-correction: j'ai optimiser les images pour qu'elles se chargent plus vite en les compressant et en utilisant l'attribut loading="lazy"
-resultat: le temps de chargement des images est optimisé

3- robustesse

- probleme: le site n'était pas très stable sur mobile; et aussi sur la page contact, les boutons étaient l'un au dessus de l'autre, sur la page projet le menu n'était pas cliquable
-correction: j'ai rendu le site responsive sur tous les écrans et j'ai corrigé les bugs sur la page contact et projet
-resultat: le site est stable sur tous les écrans et les bugs sont corrigés
